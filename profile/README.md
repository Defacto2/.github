# Defacto2

Welcome to the Defacto2 on GitHub! The website conserving defunct software, wares, and elite Scene subcultures on obsolete Personal Computers.
This is done through documenting and hosting digital artifacts including: text files, demos, music, art, magazines, and other projects.

Please feel free to contact _.defacto2_ at [Demozoo on Discord](https://discord.gg/AJ2xV8X) or email.

- Also, there is a RESTful API: [defacto2.net/api](https://defacto2.net/api).
- And a complete SQL database document: [defacto2.net/sql/files.sql](https://defacto2.net/sql/files.sql).

### 💾 &nbsp; [Defacto2 server](https://github.com/Defacto2/server)

Our custom, open sourced, website application server programmed in [Go](https://go.dev/).

### 💾 &nbsp; [Defacto2 database](https://github.com/Defacto2/database)

The database repository has information on obtaining and using the Defacto2 website database.

### 💾 &nbsp; [Sceners](https://github.com/sceners)

Sceners is our collection of historical code sources for scene tools, demos, intros, and magazines found through file submissions to the website.

### 💾 &nbsp; [Scene websites](https://github.com/Defacto2/websites)

The websites repository is our collection of historical and defunct web documents created by the Scene.
